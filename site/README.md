Pasta pronta para enviar ao GitHub.

Conteúdo:
- `index.html` — página com mensagem e animações.

Como usar

1. Faça upload da pasta `site` para o repositório GitHub.
2. Para publicar via GitHub Pages, você pode:
   - Renomear o conteúdo para a pasta `docs/` na raiz do repositório e ativar GitHub Pages no branch `main` apontando para a pasta `/docs`.
   - Ou publicar a partir da `main` configurando a raiz (se preferir, movo os arquivos para `docs/` para você).

Link direto após publicar (exemplo):
`https://SEU_USUARIO.github.io/NOME_DO_REPO/index.html?open=1`

Se quiser, eu movo os arquivos para `docs/` automaticamente e preparo instruções para ativar o Pages.
